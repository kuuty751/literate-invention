温度 0 + 固定 seed 保证同一道题每次给的结论和形状一样（实测关掉缓存连问三次， 有一次把算式加了空格、换了措辞，但选哪个从不漂）；一个字都不差靠问答缓存兜住： 温度锁 0 的角色每轮回答都存进 kb/collections/qa.json，同义改写也回放同一份文本。 温度只要大于 0，百炼即使给了同一个 seed 也仍会换写法（实测 0.2 连问三次得到三种答案）， 所以温度 >0 的角色不查也不写缓存。 内置角色自带的温度会覆盖这里：课程老师 / 医生 / 知识库问答锁在 0， 婴儿取名、周公解梦、爱莉希雅故意留 0.8~0.9（那三个要的就是每次给一批新的）。
